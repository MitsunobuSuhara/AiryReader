# airyPDF 1.1

Windows 11 x64用のPDFデスクトップアプリ。原寸・指定倍率の印刷、連続スクロール、標準PDFの入力・注釈・検索・しおり・証明書署名を備えます。黒単色背景と3つの白い面の羽根（B案）を採用しています。

## インストール・起動

セットアップ一式を展開し、Setup.cmdを実行します。Windowsの管理者確認後に C:\Program Files\airyPDF へ.NETとPDF編集エンジンを同梱して登録します。デスクトップ・スタートメニュー・既存のタスクバーピンを更新します。実行ファイルは C:\Program Files\airyPDF\airyPDF.exe です。更新時はairyPDFを閉じてからSetup.cmdを実行します。PDFを右クリック→「プログラムから開く」でairyPDFを選び、既定に設定できます。

PDFの「プログラムから開く」にairyPDFを追加します。既定のPDFアプリは変更しません。設定はユーザーのLocalAppData/airyPDFに保存します。登録解除はWindowsのアプリ一覧から行います。登録と自分のリンクを解除し、実行ファイルと設定は復旧用に残す方式です。

別PCで使用する場合も.NETやPythonの追加インストールは不要です。プリンタードライバーはそのPCで導入してください。パッケージに社内IP、プリンタードライバー、個人のPDFや証明書は含めません。

## PDFの閲覧・印刷

PDFを開く：Ctrl＋O、またはドラッグ＆ドロップ。複数ファイルはタブになります。ホイールでページを連続スクロール、Ctrl＋ホイールで拡大縮小。ページ番号入力と左右ボタンでも移動できます。

印刷：Ctrl＋P。原寸・指定倍率、用紙合わせ、2／4アップ、小冊子、ポスター分割に対応します。設定変更はプレビューへ自動反映します。新しいPDFの印刷倍率は100%。指定倍率で勝手に縮小せず、欠けをプレビューで知らせます。

ドライバー側の拡大縮小・Nアップ・小冊子は無効にしてください。小冊子は横向き・短辺とじ両面、ポスターは片面です。回転は別名保存で原本を保護します。

2026-09-14、利用者が会社のApeos C3571で印刷し「約0.1mmのずれに見えるが用途では完璧」と評価しました。厳密な測定条件とAcrobatとの同条件比較結果は未取得です。フォームの印刷は本文をPDFiumから直接描画し、入力欄の見た目だけ透過画像を重ねます。

## パスワード・入力・注釈・検索・しおり

パスワード付きPDFは開く際にパスワードを入力します。入力値を設定ファイルやログには保存しません。編集した暗号化コピーは入力したパスワードで暗号化し、元の権限を引き継ぎます。

「入力・注釈・検索・署名」またはCtrl＋Fで操作画面を開きます。

- 入力欄：標準AcroFormの文字欄、チェック欄、単一選択欄に記入して別名保存。保存後も欄を残します。変更した欄だけ書き換え、文字数制限と1文字ごとの枠にも対応します。一般編集は禁止でもフォーム入力が許可されたPDFは記入可能です。
- 文字・注釈の追加：現在ページの左上からの位置をmmで指定し、日本語文字、付箋、しおりを追加して別名保存。欄のないPDFにも記入できます。既存注釈も一覧で読みます。
- 検索：文書本文から検索文字を含むページを一覧表示し、ダブルクリックで移動。OCRと検索文字のハイライトは未対応です。
- しおり：既存しおりを一覧表示し、ダブルクリックで移動。

保存したコピーは新しいタブで開きます。原本を上書きしません。

## 電子署名

PFX／P12証明書とパスワードを選び、別名保存したPDFへ証明書署名を付けます。画像や名前だけの見た目の署名とは異なります。利用者の実証明書は未取得です。テスト専用の自己署名証明書で署名・検証・改ざん検出を確認しています。

「署名を確認」は署名対象の改ざん、署名値、証明書の信頼、署名後の変更、対象範囲を別々に表示します。Windows ROOTストアを使うオフライン検証です。オンラインOCSP／CRLの失効確認は初版では行いません。未確認を画面に明示し、署名値の一致だけで全面的に正しいとは表示しません。

署名済みPDFは編集・回転・再保存を止め、原本の署名を保護します。複数署名の追加、ICカード／PKCS#11、タイムスタンプ付与と長期検証用データの追加は未対応です。

## 互換性と未対応

Adobe Acrobat Standard DCで作成された、2ページ・80文字欄の暗号化PDF（一般編集禁止・フォーム入力許可）を利用者が提示しました。検証コピーへの日本語保存、ページ数と80欄の保持を確認しました。原本・検証コピー・個人情報はGitへ保存しません。PDFiumとPopplerの2つのエンジンで保存後の見た目も確認しました。

標準AcroFormを対象とします。Adobe独自XFA、JavaScriptによる自動計算・検証、ラジオ／押しボタンの変更、複数選択欄、リッチテキストの編集は未対応です。XFAと対象外の欄は区別して編集を止めます。付箋以外の注釈作成、注釈削除、しおりの編集・削除、OCRは今後追加します。Adobeの全機能・全形式との互換性を保証する段階ではありません。

512MB超のPDFは非対応。大きなページ数の性能、特殊フォント・透明効果・複雑なフォームの代表資料、実機両面・小冊子は今後評価します。ポスターの紙上番号・切り取り線は未実装です。

## 開発・検証・パッケージ

.NET SDK 10.0.401とPython 3.12 x64の専用環境 .tools/pdf-helper-env を使用します。補助エンジンの依存バージョンはsrc/pdf-helper/requirements.lock.txtで固定します。

1. scripts/build-pdf-helper.ps1 -InstallDependencies：補助エンジン作成とフォーム・暗号化・署名検証。
2. scripts/build.ps1 -Test -Publish：.NETビルド、PDFium・Windows仮想印刷・画面の検証、実行一式作成。
3. scripts/package.ps1：Setup.cmd付きZIP作成。

テストは生成したPDFとMicrosoft Print to PDFを使い、物理プリンターへ送信しません。PDFiumはbblanchon.PDFium.Win32 155.0.8044を固定し直接P/Invokeで利用。フォーム編集はpypdf／ReportLab、署名はpyHanko。ライセンスはTHIRD-PARTYに保存し実行一式にも同梱します。アップデートはライセンスと検証をセットで行います。コード署名証明書は未導入です。

印刷プレビューの初期用紙は、表示中の原本ページのサイズと向きに合わせます（A4横ならA4横、A3横ならA3横）。プリンターに同じサイズの用紙がない場合はA4など利用可能な用紙を選びます。倍率・用紙・範囲などの変更は入力が止まって約0.25秒後に自動反映し、更新中や不正な入力では印刷を無効にします。

閲覧画面の上部は「開く・印刷・保存・編集／検索」と「その他」に整理しています。表示倍率は10～800％を手入力してEnterで確定、100％も手入力できます。Ctrl＋ホイールは100％をまたぐときに一度100％で止まり、次の操作で先へ進みます。「画面幅に合わせる」は画面の幅への表示調整です。回転は矢印アイコンで操作し、全ページへの適用は「その他」で選べます。範囲選択と選択解除は閲覧画面から削除しました。タブを閉じるショートカットはCtrl＋Wです。

印刷プレビューはホイールでも前後の面へ切り替えられます。画面内をスクロールし、下端で次の面、上端で前の面へ進みます。2アップ・小冊子・ポスターでは印刷される面の順に切り替えます。
印刷倍率・部数・貼り合わせ幅はクリックで全選択されます。倍率と部数は上下矢印ボタン／キーボードの上下で1ずつ調整できます。貼り合わせ幅はポスター印刷を選んだときだけ表示します。
印刷画面はモニターの作業領域内に収めて開き、「この設定で印刷」ボタンを左上に固定しています。設定欄をスクロールしてもボタンは残ります。
