# airyPDF

Windows 11用の軽量PDFリーダー。黒背景と白い羽根のアイコンを採用した、個人・業務で使うデスクトップ版1.0です。

## 起動

デスクトップまたはスタートメニューの「airyPDF」から起動します。タイトルが「airyPDF 1.0」であることを確認してください。既存のairyPDFのタスクバーピンも登録時に更新します。1.0版には.NETランタイムを同梱し、ユーザー専用のアプリフォルダに登録します。開発用フォルダを開く必要はありません。

PDFを画面にドラッグするか「PDFを開く」を選択します。複数ファイルはタブで開きます。ホイールで複数ページを縦に続けてスクロールできます。Ctrl＋ホイールで拡大縮小、左右のページボタンやページ番号入力でも移動できます。画面付近だけ画像を描画し、離れたページの画像は解放します。

## 使える機能

- タブ、ページ移動、幅に合わせる、ポインターを中心としたズーム
- 現在ページ／全ページの90度回転、別名保存、未保存変更の確認
- 印刷プレビュー、原寸・指定倍率、用紙に合わせる、2／4ページを1枚に配置
- 小冊子（左右とじ・端数の空白補充）、範囲選択、ポスター分割と重なり幅
- プリンターが対応する用紙、向き、片面／両面、ページ範囲、部数

新しいPDFの印刷倍率は100%です。表示倍率とは独立しています。原寸・指定倍率では自動縮小せず、印刷可能範囲を超えるとプレビューに知らせます。設定を変更したら「プレビューを更新」してから印刷します。

回転は元PDFを保護するため別名保存します。小冊子は横向き・短辺とじ両面を指定します。ポスターは片面です。選択範囲は現在ページにだけ適用します。

ドライバー側の拡大縮小・Nアップ・小冊子設定は無効にしてください。アプリと二重に適用されると寸法が変わります。

## 検証状況・未完成の部分

Microsoft Print to PDFを通した50%・100%・200%の縦横基準線、A4縦とA3横、回転保存、配置計算、WPF画面の検証を実施。2026-09-14、利用者が会社で印刷し、寸法は約0.1mmのずれに見えるが用途上は完璧との評価を受けました。これは利用者の実使用評価であり、測定条件やAcrobatとの同条件比較結果は未取得です。

- この開発PCには公式ART EX 7.1.10と「Apeos C3571 (ART EX)」を登録済み。プリンター切替とプレビューまで検証し、実機への通信・紙出力は会社で確認します。
- ポスターの紙上の用紙番号・切り取り線は未実装（画面には行列番号を表示）。
- 検索・しおりは未実装。画面サイズと最大化状態は記憶します。印刷倍率は新しいPDFごとに100%で開始します。
- パスワード付きPDF、512MBを超えるPDFはこの版では非対応。編集・高品質印刷の権限制限がある場合は該当操作を止めます。
- フォーム、電子署名、特殊なページ領域・フォント・透明効果を含む実際の業務PDFは未検証。電子署名付き原本の再保存用には未評価です。
- 高倍率では画面描画のメモリを制限しています。大きな図面の操作速度は代表PDFで今後評価します。
- 採用PNGから専用ICOを作成し、アプリとショートカットに使用。外周の透過整備は未実施です。

## 会社で最初に行う印刷チェック

1. 会社のネットワークへ接続し、airyPDFの「寸法確認用PDF」を開きます。
2. 印刷画面で「Apeos C3571 (ART EX)」、A4・縦・片面・1部・ページ範囲「1」、原寸／指定倍率100%を選びます。
3. 「プリンターの設定」で、ドライバー側の拡大縮小、Nアップ、小冊子を無効にします。「プレビューを更新」で確認し、1枚だけ印刷します。
4. 横と縦の100mm基準線を、それぞれ両端の目盛の中心間で測ります。同じPDFをAcrobat Readerでも「実際のサイズ」で印刷し、同じ条件で比較します。
5. A3はページ範囲「3」、A3・横・100%で確認します。最初の寸法確認では全4ページをまとめて印刷しないでください。

寸法確認用PDFは全4ページです（A4縦、A4横、A3横、A4縦）。同じPDFがアプリの `Samples/print-check.pdf` にあります。記録する項目は、アプリ名・ページ番号・用紙・倍率・横の実測mm・縦の実測mmです。両面や小冊子は片面の寸法確認後に別に試します。

印刷できないときはWindowsのプリンター設定で会社ネットワーク上の接続とエラーを確認します。この版のPC登録は接続先の実機が応答したことを意味しません。

登録し直す場合は、.NET同梱フォルダの `airyPDF.exe --install`、または画面の「使い方・登録」を使います。Apeosの再登録用スクリプトは `scripts/install-apeos.ps1` です。接続先は引数で指定し、社内IPはGitへ保存しません。
## 開発・検証

.NET SDK 10.0.401（Windows x64）が必要です。Microsoft公式のdotnet-install.ps1等で `.tools\dotnet` に導入するか、PATHのdotnetを利用します。

```powershell
.\scripts\build.ps1 -Test -Publish
```

テストは自動生成したPDFを使用し、Microsoft Print to PDFへファイル出力します。物理プリンターへは送信しません。結果と画面画像は `artifacts` に生成します。`artifacts`、SDK、ビルド生成物、ドライバー実体はGitへ含めません。

PDFiumは `bblanchon.PDFium.Win32 155.0.8044` を固定し、直接P/Invokeで利用します。ライセンス文書は `THIRD-PARTY` に保存し実行用フォルダにも同梱します。更新時はパッケージとライセンスを同じ版に更新し、PDF描画・保存・印刷の検証を再実施します。

## Windowsへの登録

ユーザー専用に登録し、Windowsのアプリ一覧とPDFの「プログラムから開く」にairyPDFを追加します。既定のPDFアプリは変更しません。登録解除はWindowsのアプリ一覧から行えます。解除は登録と自分のショートカットを除き、実行ファイルと設定は復旧用に残します。
